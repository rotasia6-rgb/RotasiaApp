# Feature Links Analysis

Here is an analysis of the features and their corresponding links based on the project structure:

| Feature Name | Route | Description |
| :--- | :--- | :--- |
| **Dashboard** | [/dashboard](http://localhost:3000/dashboard) | Main event stats, KPI cards, and admin tools. |
| **Best Attire** | [/best-attire](http://localhost:3000/best-attire) | Submit nominations for "Best Attire". (Requires Login) |
| **Voting Poll** | [/voting](http://localhost:3000/voting) | Public voting page for "Mr. & Ms. Rotasia". |
| **Feedback Submission** | [/feedback](http://localhost:3000/feedback) | Submit feedback about the event. (Requires Login) |
| **Feedback Wall** | [/feedback/wall](http://localhost:3000/feedback/wall) | View public feedback. |
| **Find My Room** | [/find-my-room](http://localhost:3000/find-my-room) | Search for room allocation and roommates. |
| **Scan (QR)** | [/scan](http://localhost:3000/scan) | QR Code scanner for event entry/tracking. (Protected) |
| **Login** | [/login](http://localhost:3000/login) | User authentication page. |
| **Speed Networking** | [/speed-networking](http://localhost:3000/speed-networking) | Registration or info for speed networking. |
| **Open Mic** | [/open-mic](http://localhost:3000/open-mic) | Open mic event details/registration. |
| **Idea for Rotaract** | [/idea-for-rotaract](http://localhost:3000/idea-for-rotaract) | Submit ideas. |
| **Mr. & Ms. Rotasia** | [/mr-ms-rotasia](http://localhost:3000/mr-ms-rotasia) | Info/Registration page (might be closed). |
